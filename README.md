# National Secure Ideas Submission

Downstream implementation of the Secure Innovation Gateway ("American Innovation Shield") described in the **National Secure Ideas Submission Act of 2025**.

This repository contains application-specific policy, configuration, deployment files, and any genuinely specialized code. Reusable case-management behavior belongs upstream in:

`neophilism/Secure-Intake-Case-Workflow-Engine`

> **Security boundary:** this repository is not an accredited system for classified information. Until an appropriately authorized classified submission environment is integrated, this application must not accept classified information through its ordinary web intake.
